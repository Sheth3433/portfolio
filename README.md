## About this site

I built this portfolio with HTML, CSS, and JavaScript. It works on phones and computers, and doesn't need a build step or extra packages.

To view it, open `index.html` in your browser. The images, certificates, and resume are in the `assets` folder, so keep that folder next to the page.

The contact form opens a pre-filled email in your email app. You can review it and send it from there.
